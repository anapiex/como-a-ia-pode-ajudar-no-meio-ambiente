# 🌿 IA no Combate à Poluição (Fluxograma Interativo)

Um projeto interativo desenvolvido em HTML, CSS e JavaScript que ilustra como a Inteligência Artificial auxilia a humanidade a monitorar, identificar e reduzir a poluição do ar, da água e do solo.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica do fluxograma.
- **CSS3**: Layout responsivo (Flexbox), animações e paleta de cores terrosas (verde e marrom).
- **JavaScript (Vanilla)**: Dinâmica de interação ao passar o mouse ou clicar nos cards.

## 📋 Como Visualizar o Projeto

### Localmente
1. Baixe ou clone este repositório para o seu computador.
2. Abra o arquivo `index.html` em qualquer navegador web.

### Online (GitHub Pages)
1. Acesse as **Settings** deste repositório no GitHub.
2. No menu lateral, vá em **Pages**.
3. Em **Branch**, selecione `main` e clique em **Save**.
4. Acesse o link gerado pelo GitHub para ver o site no ar!
